How AI Agents Should Use Strata

  1. Actionable categories (agent-consumable): mcp-protocols, agent-templates, agent-infra, agent-skills, ai-prompts, components, libraries, security, motion, micro-interactions, ux-flows, icons-assets, design-systems -- these are directly consumable by agents via /llms.txt, /llms-full.txt, /catalog.json, /api/a2a.
  2. Visual reference categories: components, landings, motion, micro-interactions, typography, ux-flows, icons-assets, design-systems -- useful for inspiration where resources are not agent-consumable.
  3. Endpoint selection: /llms.txt (index), /llms-full.txt (Markdown), /catalog.json (GET JSON), /api/a2a (JSON-RPC 2.0 POST for filtering/searching).
  4. A2A examples: list_categories, filter_by_category, search_resources, get_resource_details.
  5. Free MCP servers: 43 indexed with the free-mcp tag — query them with search_resources: free-mcp (limit up to 60).
  6. Agent Templates: 40 deployable starter kits indexed with the agent-template tag. Filter with filter_by_category: agent-templates or by archetype: template-starter, template-research, template-multi-agent, template-coding, template-browser, template-voice, template-ui, template-local.
